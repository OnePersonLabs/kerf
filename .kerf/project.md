# Kerf

Help a person and Codex make coherent changes to a large project without rebuilding
their understanding of the whole project on every request. Preserve purpose,
behavior, relationships, boundaries, and reasons in readable, revisable meaning.
Code is one replaceable realization.

The bet is practical: a small connected loop can retain the right understanding
with less overhead than repeatedly reading either a repository or a complete spec.
Success still needs evidence from real project work.
